# Robert's Recipe Box v83.12 Shopping Ingredient Report

## Default Shopping View

Shopping List now opens in **By Meal / Component** view. The same view is restored after **Clear & Start Over** so users begin with the detailed meal-level list rather than the consolidated aisle list.

Every stored ingredient for a planned recipe remains visible in this view. Pantry or prepared-inventory matches are identified, but no ingredient is automatically hidden; users can check each row themselves.

A dedicated recipe-card-verified override layer was added to the recipe registry. It takes priority over broad category estimates while preserving those estimates as fallbacks for recipes whose full structured ingredient records have not yet been entered.
