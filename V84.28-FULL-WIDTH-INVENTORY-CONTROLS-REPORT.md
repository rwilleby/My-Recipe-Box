# v84.28 Full-Width Inventory Controls

## Result

The Master Kitchen Inventory command strip now spans the established 90% content width, matching the left and right gutters used by the large hero and other full-width control rows.

## Desktop layout

The row is divided into seven equal control positions:

**KITCHEN | FREEZER | PANTRY | QUICK ADD | MOVE ITEM | PRINT | CLEAR**

The KITCHEN, FREEZER, and PANTRY selectors remain one segmented group, but that group occupies exactly three of the seven positions. Each action occupies one position.

## Responsive behavior

The full-width row remains centered. On narrower screens, the three inventory selectors move to a full first row and the four actions divide the following row evenly. On small phones, actions use two columns.
