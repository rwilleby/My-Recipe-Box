## Title and card alignment

The old recipe registry contained many titles that did not describe the image card attached to the same AM code. The repository already had a correct, code-by-code title mapping in `src/data/nutrition/AM.json`. v84.9 uses that existing authority to realign the public recipe titles without changing any AM code.

Examples include:

- AM-011: Beef and Noodles → Smothered Chicken
- AM-021: Chicken and Dumplings → Hamburger Gravy over Mashed Potatoes
- AM-033: Ham Steak Dinner → Chicken Noodle Casserole
- AM-051: Tuna Noodle Casserole → Sausage Gravy & Biscuits
- AM-061: Club Sandwich → Hot Dogs & Beans

This correction ensures that the recipe listing, displayed card, Nutrition Database, and Shopping List all describe the same dish.

## AM-063 retirement

AM-063 is a printed placeholder asking for a future recipe; it is not a completed recipe card. It has been removed from the active recipe registry, consistent with the Nutrition Database. Its existing image asset remains in the repository for historical reference, so no file deletion is required.

## Ingredient handling

- Exact printed quantities, package sizes, preparation wording, and optional ingredients are retained.
- Printed 3–4 lb ranges remain visible in the ingredient name while the Shopping List treats the requirement as one ham or roast.
- Combined “salt and black pepper” card lines are separated so users can check each grocery item independently.
- By Meal / Component continues to show card-level detail; the Consolidated List continues to apply the normalization layer added in v84.7 and v84.8.
