# v84.31 Inventory Control Strips

## Master strip

The seven-part master strip now remains one row at 100% width across all responsive breakpoints:

**KITCHEN | FREEZER | PANTRY | QUICK ADD | MOVE ITEM | PRINT | CLEAR**

The three inventory selectors occupy three equal shares, and each action occupies one equal share. Legacy tablet and phone rules can no longer force the tabs or actions onto another row.

## Freezer secondary strip

The Freezer selector is a single 90%-wide row. Each segment contains its corresponding live count:

- Complete Meals: available frozen meal packages
- Individual Recipes: available frozen recipe packages
- Component Items: component products marked on hand

## Pantry secondary strip

The Pantry level selector uses the same 90%-wide, single-row treatment. Each number is the cumulative count of items currently marked In Stock through that level:

- Minimum Pantry: Level 1 stocked items
- Medium Pantry: Levels 1–2 stocked items
- Fully Stocked Pantry: Levels 1–3 stocked items

## Simplification

The separate Freezer and Pantry summary-card rows were removed because their primary category counts now live inside the secondary control strip.
