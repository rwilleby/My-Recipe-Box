# v84.23 Shopping List Stacked Labels Report

## Adjustment

Each multiword command label now uses two centered lines. This reduces the horizontal space required by the view selector and action buttons while keeping the full wording visible.

The complete strip remains one row in this order: view selector, Preview, Print List, Stock Check, Digital Check, Grocery Picks, Clear & Start Over, and the four live counters.

## Sizing

- Control height: 46 pixels.
- View selector minimum width: 170 pixels.
- Compact counter group minimum width: 240 pixels.
- Counter cards: four equal columns with reduced label typography.
- Desktop horizontal scrolling: removed.
- Below 900 pixels: safe one-row horizontal scrolling remains available.
