# v84.22 Shopping List One-Row Report

## Layout

The Shopping List command strip now remains one continuous left-to-right row. The view selector and six actions use reduced widths, tighter padding, smaller gaps, and compact typography while preserving all existing functions and one-line labels.

The four live shopping counters now occupy the final position in that same row. Each counter is a compact 40-pixel card showing its existing label and current value.

## Counter continuity

The original Kitchen Operations shopping-status component was moved rather than duplicated. Its subscription and values remain unchanged, and the previous standalone counter band was removed.

## Narrow screens

The row does not wrap. When the available viewport is narrower than the safe minimum width, horizontal scrolling becomes available so control order, label integrity, and counter placement are preserved.
