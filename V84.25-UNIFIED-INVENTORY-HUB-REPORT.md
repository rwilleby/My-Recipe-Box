# v84.25 Unified Kitchen Inventory Hub

## Result

Kitchen, Freezer, and Pantry Inventory now appear as three views inside one Kitchen Inventory page. The master segmented control defaults to Kitchen for a new user and remembers the last selected view on that device.

The KITCHEN DETAILS menu now contains one KITCHEN INVENTORY destination. Older internal links to Freezer Inventory Management and Pantry Staples remain compatible and open the unified page on the requested tab.

## Master controls

- KITCHEN | FREEZER | PANTRY
- Search with Current Section or All Inventories scope
- Restock List
- Quick Add
- Move Item
- Print
- Backup & Restore

## Inventory and Shopping integration

- Kitchen products support In Stock, Low, and Out status alongside existing Have and Buy quantities.
- Pantry products support In Stock, Low, and Out status, including Quick Add custom products.
- Existing products begin as Not Set unless prior inventory data establishes that they are on hand; this prevents a new or cleared inventory from sending every catalog product to Restock.
- The Restock List combines Kitchen Buy/Low/Out items, Freezer grocery selections, and Pantry Low/Out items.
- All three restock sources feed the Shopping List and printed shopping data through the existing shopping pipeline.
- Storage transfers update the standardized Kitchen Inventory record without deleting and recreating the product.

## Preservation

The existing Kitchen, Freezer, Prepared Freezer, and Pantry data stores remain separate underneath the unified interface. Existing saved inventory is not migrated or deleted. Inventory content continues to use the Recipe Box browser backup because the new Pantry metadata is stored with the existing Pantry record and Kitchen/Freezer records use their existing storage keys.
