# v84.21 Shopping List Command Strip Report

## Design

The Shopping List actions now follow the approved Weekly Planner command-strip visual language: one centered row, consistent 44-pixel control height, 18-pixel corner radius, restrained green outlines, and compact bold labels.

The view choices remain one segmented control. Its selected segment uses the approved muted gray/taupe treatment with white text. Print List is the olive primary action, while Clear & Start Over remains a clearly separated red outlined destructive action.

## Responsive behavior

- Wide desktop: one complete horizontal command strip.
- Narrow desktop and tablet: the view selector spans the row and actions use three columns.
- Small tablet and phone: actions use two columns.
- Narrow phone: controls stack in one column.

## Preserved functions

No shopping behavior changed. Consolidated List, By Meal / Component, Preview, Print List, Stock-Check, Digital Check, Grocery Picks, and Clear & Start Over retain their existing handlers and saved data behavior.
