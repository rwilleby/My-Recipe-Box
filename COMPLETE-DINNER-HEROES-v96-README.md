# Complete Dinner hero rebuild v96

This upload contains 68 visually audited replacement WebP heroes in:

`public/images/dinner-combinations/`

The files are named `meal-045.webp` through `meal-111.webp`, plus
`meal-116.webp`. Meals 112–115 and 117–131 are intentionally absent and must
remain unchanged.

`src/utils/completeDinnerAdapter.js` includes the activation change that marks
these 68 rebuilt assets as available while preserving all previously approved
catalog heroes.

All replacement images are 1448×1086 WebP exports at quality 88.
