ROBERT'S RECIPE BOX — V81b SPLIT DOWNLOAD SET

The split ZIP files collectively contain one complete My-Recipe-Box-V81b
project. The project is divided only so every download remains below the chat
file-size boundary.

PART 01 contains the complete project structure, source code, data, tests,
configuration, Complete Dinner images, product images, and supporting images.

PARTS 02–11 contain the videos, full-size recipe cards, full-size hero images,
and optimized thumbnails in their correct project paths.

To assemble locally, unzip Part 01 first. For every later part, merge its
My-Recipe-Box-V81b folder into the Part 01 My-Recipe-Box-V81b folder. Preserve
the included public/images and public/videos paths. Do not rename individual
files.

For a GitHub folder-by-folder upload, upload Part 01 first, then upload the
contents of Parts 02–11 into the matching paths already provided inside each
ZIP.

Do not upload node_modules or dist. GitHub/Vite regenerates them from the
included package files and build workflow.
