# Robert's Recipe Box v83.1 Structural Report

## Purpose

v83.1 begins an incremental, appearance-preserving reduction of the monolithic `App.jsx` and `App.css`. It deliberately avoids a full rewrite and does not introduce new visible features.

## Extracted ownership

### Home

- `src/features/home/HomeRecipeCounters.jsx`
- `src/features/home/AdminPinDialog.jsx`
- `src/features/home/AdminPinDialog.css`

### Recipe Viewer

- `src/features/recipe-viewer/recipeAssets.js`
- `src/features/recipe-viewer/RecipeImages.jsx`
- `src/features/recipe-viewer/BrowseRecipeNutritionFacts.jsx`

## Result

- `App.jsx` reduced from more than 20,000 lines to fewer than 19,700.
- Isolated Admin PIN dialog CSS removed from `App.css` and owned by its component.
- Recipe image fallback paths are defined once and contain no redundant results.
- Existing Home and Browse Recipes class names and rendered structure remain intact.
- Existing tests were redirected to the new authoritative modules rather than weakened or removed.

## Verification

- Active release suite: passed.
- v83.1 structural and accessibility contracts: passed.
- Production Vite build: passed.
- No recipe, nutrition, media, storage, or user-data schema changes were introduced in v83.1.

## Recommended v83.2 extraction

Continue with the Home Meal Journey and Home category/rotation sections, then separate the Recipe Viewer popup shell. Move CSS only when a selector group has one clear owner and can retain its exact cascade order.
