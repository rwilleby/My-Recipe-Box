MY-RECIPE-BOX v66.2 — PRODUCTION CENTER ENGINEERING
==================================================

BASELINE
--------
Current local Master based on v66.1.2 or later.

IMPORTANT
---------
This is an engineering integration package. It does not contain App.jsx,
homepage components, CSS, or images, so it will not overwrite approved UI work.

COPY
----
Copy all included files into the matching locations in your current local
Master folder and replace matching files when prompted.

THEN RUN
--------
npm install
npm run check

LOCAL REVIEW
------------
npm run dev

The new Production Center services are headless until the approved UI is wired
to them. Existing site behavior should remain unchanged.

GITHUB
------
After npm run check passes and your local site still looks correct, the merged
local Master is the version to commit/push to GitHub.
