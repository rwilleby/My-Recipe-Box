RRB POCKET PANTRY — REVISED PRODUCT FORM (VERSION 2)
For the supplied RRB v100.3 project — September 30, 2026

INSTALL
Copy the files in this ZIP into matching locations in your RRB project, replacing matching files. Keep the rest of your project. Commit them to GitHub and wait for the GitHub Actions green checkmark. For a local build: npm ci, then npm run build.
Open RRB > Kitchen Inventory > Open Pocket Pantry. The direct app page is /pantry-capture.html.

ON YOUR IPHONE
Open Pocket Pantry in Safari. Share > Add to Home Screen adds its icon.
Choose a store (Walmart, Kroger, H-E-B, Aldi, Amazon, Costco, Sam's Club, Target or Other). The store is remembered.
Enter Brand, Product name, Package size, Package type, Quantity and Storage location. Quantity starts at 1 and returns to 1 after each saved product.
Package size is the size of one package; quantity is how many you own or purchased. For example: 2 cartons of 32 fl oz each.
Choose Add newly purchased quantity to add a purchase to a matching product. Choose Set the quantity I have now to correct a count. Set 0 to mark a product out of stock.
The optional reference photo identifies the product visually. It does NOT fill in product fields. Barcode scanning and automatic label reading have been removed from this page.
Tap Save & Add Another. This saves the product in your transfer list; it does not automatically update your laptop.

SEND NEW PRODUCTS TO THE LAPTOP
1. On the phone: Review & Transfer > Send Changes to RRB.
2. Choose AirDrop to a Mac, or Save to Files (iCloud Drive). Download .json File is also available if sharing is unavailable.
3. On the laptop: open RRB > Kitchen Inventory > Import / Export Inventory.
4. Choose Open My Inventory / Import File and select the .json transfer file.
5. Review the products, then click Add to My Inventory on This Device.
6. The products are saved in the laptop's main Kitchen Inventory.
Reimporting an identical change file skips already imported changes. There is no automatic sync.
The transfer list stays available after sending. Clear Transfer List removes only the queue, not saved Kitchen Inventory records. Clear it after successful laptop import, before starting a new batch.

EDIT THE LAPTOP'S EXISTING INVENTORY
1. On the laptop: Kitchen Inventory > Import / Export Inventory > Export Inventory to My Phone.
2. Move the .json file to the iPhone with AirDrop or iCloud Drive.
3. On the phone: Open My Inventory / Import File. The My Inventory tab displays the opened list.
4. Choose Edit beside a product. Change its details or count, then Save & Add Another. Repeat as needed.
5. Review & Transfer > Send Changes to RRB sends only the products whose edits you saved.
6. On the laptop: open the returned changes file, review it, then Add to My Inventory on This Device.
Permanent product IDs let renamed products and changed brands, sizes, stores or locations update the original record. Opening an inventory file alone does not replace any saved RRB inventory.
When matching a NEW product without a known ID, name, brand, package size, store, location and unit must match exactly. RRB does not convert units or combine different brands automatically. Review the proposed match before applying.
If the laptop inventory changed after you exported it, review its current quantities before applying Set quantity edits.

PHOTOS AND SAVED DATA
Small reference photos are included in transfers and saved using RRB's existing product image storage. Product quantities, brand, store, size and notes are saved in the main inventory and covered by standard Backup & Restore.
The form, transfer list and opened inventory list remain on the current device. Your full Recipe Box backup uses the separate Backup & Restore page; it is not a Pocket Pantry transfer file.
This is a browser app, not an App Store installation. An internet connection is needed to open it. No login is required.
