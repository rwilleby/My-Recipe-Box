# KOS-120 — Intent and Action Service

## Intent contract

The service defines eight user goals:

1. I Just Need Dinner
2. Help Me Plan My Week
3. I'm Cooking Today
4. I'm Building Freezer Meals
5. Show Me What's Available
6. Build My Shopping List
7. Browse Recipes
8. Teach Me Something New

Each goal exposes the same six logical content areas:

- Start
- Workspace
- Assistant
- Suggestions
- Progress
- Wisdom

The service defines purpose and data sources, not visual layout.

## Action contract

Plain-language commands safely orchestrate KOS services:

- Cook
- Transform
- Recover
- Build meals
- Package food
- Consume food
- Preview assembly capacity
- Read current kitchen status
