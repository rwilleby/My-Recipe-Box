# v66.2 — Production Center Engineering

## Scope

This milestone adds UI-neutral services for the Production Center and Kitchen Companion.

### Production Center
- Start an active cooking session
- Persist the active session in browser storage
- Resume after page refresh/browser restart
- Update notes, yield, method, and title
- Finish cooking into KOS inventory
- Cancel without changing inventory
- Return a consolidated Production Center home model

### Available Meals
- Ready-to-eat meal inventory
- Filter by type, storage location, or search term
- Ready-meal totals
- Consumption through the existing guarded KOS action layer

### Kitchen Companion API
- Compact home summary for counter/iPad interfaces
- Active cooking state
- Ready-meal totals
- Intent-based quick actions
- Gentle assistant suggestions

## Design rule

No page layout, colors, card dimensions, or homepage design are imposed here.
The approved UI may consume these contracts without changing the engine.

## Local-first rule

Active cooking state and KOS history remain in browser-local storage and are covered by the existing KOS backup/recovery architecture.
