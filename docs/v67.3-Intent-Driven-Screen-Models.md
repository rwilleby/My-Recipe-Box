# v67.3 — Intent-Driven Screen Models

Each of the eight homepage intentions now resolves to one stable six-slot screen model.

Slots:
1. Start
2. Workspace
3. Assistant
4. Suggestions
5. Progress
6. Wisdom

Supported intents:
- I Just Need Dinner
- Help Me Plan My Week
- I'm Cooking Today
- I'm Building Freezer Meals
- Show Me What's Available
- Build My Shopping List
- Browse Recipes
- Teach Me Something New

No UI layout or styling is imposed by these contracts.
