# v66.1 — Kitchen Operations Foundation

## Included

- Versioned local KOS repository
- Automatic transaction saving and rolling recovery points
- External backup integrity verification
- Production, transformation, recovery, assembly, packaging, and consumption
- RFIS recipe and Complete Dinner bridge
- Intent and action contracts for the adaptive homepage
- Kitchen Assistant suggestions
- Kitchen Timeline
- Kitchen Memory
- Production Templates
- Opportunity Engine

## Privacy

All personal kitchen history remains in the user's browser unless the user explicitly exports a backup. No account, email address, membership, or remote profile is required.

## UI scope

This release does not overwrite homepage design work. It provides the engineering services the approved UI can consume.
