# v84.20 Shopping Print Preview Report

## Corrected behavior

The printable shopping list is now built from the unchecked recipe and component contributions in the By Meal / Component view. Filtering occurs before ingredient normalization and consolidation. This means checking one recipe's contribution removes only that contribution; any unchecked requirement for the same normalized grocery product remains and prints at its reduced combined quantity.

Checks made in the Consolidated List or Digital Stock Check are also honored. Prepared components selected for purchase use the same remaining-requirement calculation.

## Preview

The new Preview button opens the exact printable document without automatically starting the browser print dialog. The preview includes a Print This List button. Its preview toolbar is hidden by the print stylesheet, so it never appears on paper.

The existing Print List button remains available for direct printing.
