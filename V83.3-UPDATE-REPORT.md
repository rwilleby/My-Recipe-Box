# Robert's Recipe Box v83.3 Update Report

## Crock Pot nutrition

All 180 Crock Pot recipes now display clearly labeled estimated nutritional ranges when no audited stored nutrition profile is available. Existing audited nutrition remains authoritative and is never replaced by the fallback.

The range notice explains that brands, portions, retained sauce, and optional serving additions can change the totals. This avoids presenting false ingredient-level precision while filling the previously empty Nutrition Facts box.

## Responsive layout

- Large-hero paragraph type is reduced between 721 and 1100 pixels and constrained inside the hero depth.
- The desktop header now follows the preferred iPad structure, with the logo first and the full main navigation underneath.
- Home category icons use ten centered columns with the remaining four centered on the second row.
- Browse Recipes category icons use ten centered columns with the remaining three centered on the second row.
- Phone layouts retain a five-column category grid.

## Verification

- All 180 CP recipe IDs return a populated estimate.
- Non-CP recipes never receive the CP fallback.
- Full active regression suite passed.
- v83.1.1 runtime repair and v83.2 structural contracts remain active and passed.
