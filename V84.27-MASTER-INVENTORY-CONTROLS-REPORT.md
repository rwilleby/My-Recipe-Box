# v84.27 Master Inventory Controls

## Result

The unified inventory destination is now named **Master Kitchen Inventory** in the main menu, page hero, section heading, and standalone Kitchen Inventory heading.

## Command strip

The master strip has been reduced to the requested controls and centered as one compact group:

**KITCHEN | FREEZER | PANTRY | QUICK ADD | MOVE ITEM | PRINT | CLEAR**

The three inventory selectors remain a unified segmented control. Quick Add and Move Item retain their existing tools, and Print continues to use the browser print workflow.

## Clear protection

Clear displays a confirmation naming the selected inventory. It only resets the active section:

- Kitchen clears Kitchen records and custom Kitchen products.
- Freezer clears managed meals, recipes, and Freezer component records.
- Pantry clears Pantry stock records.

It does not clear the other two inventories.

## Responsive behavior

The desktop command strip uses content-sized columns and automatic left/right margins for true centering. On narrower screens, the inventory tabs occupy the first row and the action buttons reflow evenly.
