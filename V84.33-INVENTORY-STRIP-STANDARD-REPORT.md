# v84.33 Inventory Counted Strip Standard

## Locked section standard

The approved Freezer secondary strip is now the visual standard for counted segmented controls within Master Kitchen Inventory. It uses three equal segments, 14px bold labels, the muted taupe selected state with white text, and a white count circle placed toward the right edge.

## Pantry alignment

The Pantry level strip now uses the same dimensions, dividers, active-state contrast, typography, and count placement as Freezer. The prior Pantry-specific uppercase and muted-label rules no longer override the shared treatment. “Fully Stocked Pantry” displays in full at desktop widths.

## Pantry action buttons

The five Pantry commands remain in one coordinated row on desktop. Tablet and phone layouts wrap responsively so labels remain usable.
