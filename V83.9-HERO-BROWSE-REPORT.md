# Robert's Recipe Box v83.9 Hero and Browse Report

## Desktop Hero Correction

The compact paragraph typography introduced to keep iPad page-hero text inside the fixed hero depth was tied only to viewport width. A desktop browser using the same width could therefore receive the iPad size.

The compact rule is now limited to touch-first tablet input at 721–1100px. Desktop browsers again use the original page-hero paragraph standard:

- 15px body text
- 1.45 line height
- Original desktop positioning and spacing

The existing iPad fit correction remains active on touch-first tablets.

## Browse Recipe Library Categories

The Browse Recipe Library quick-category grid now matches the approved Cuisine Quick Links arrangement:

- Row one: Favorites, American, Asian, Italian, Mexican, Seafood, Diet Meals, Quiche & Pies, Casseroles, Crock Pot
- Row two: Salads, Meats, Side Dishes, Desserts
- Both rows remain horizontally centered.

Favorites opens the existing Favorites page. All other icons retain their existing recipe-filter behavior.
